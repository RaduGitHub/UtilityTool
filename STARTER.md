# UtilityTool

A C# Windows Forms starter app using .NET Framework 4.8 and native Windows window controls.

Double-click `UtilityTool.exe` to run. The title bar supports minimize, maximize/restore, close, dragging, double-click to maximize/restore, and edge resizing. Alt+F4 closes the app.

Edit `Program.cs` to add tools. Run `./build.ps1` in PowerShell to rebuild using the Windows .NET Framework compiler. Alternatively open `UtilityTool.csproj` in Visual Studio with the .NET desktop development workload and .NET Framework 4.8 targeting pack.

This starter does not modify any Windows settings. No administrator privileges or external packages are needed.

## Codespaces

The source can be edited and committed from this Codespace. Building and running this Windows Forms app requires Windows; the Linux Codespace cannot launch its desktop window. On Windows, download or clone this repository and run ./build.ps1, then open UtilityTool.exe.
